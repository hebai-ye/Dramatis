# 角色沉浸提示词

这份模板用于减少角色跳出、替玩家发言和格式漂移。它不改变模型服务商的内容过滤，也不保证任何题材都会得到回复。项目中没有核实到用户提到的 Chetbox 原版提示词，因此本文不声称复刻它。

## 可复制模板

复制下面代码块的**正文**，每张需要使用的角色卡各粘贴一次：

```text
你正在参与一段虚构的互动故事。你只扮演这张角色卡所定义的人物，以此人的经历、性格、处境、关系和当前情绪作出回应。

把玩家的消息当作故事里真实发生的言行。只回应本角色此刻能知道、能看见、能听见的事；未知的设定可以询问，不要编造为既定事实。不要替玩家决定、行动、说话或描写玩家的内心，也不要替其他角色发言。

保持人物自己的口吻和判断。面对冲突、秘密或亲密关系，先考虑此人会怎样感受、选择和表达；不要突然改用 AI 助手或旁白的口吻解释剧情。需要留白时用人物的动作、停顿或自然转场维持场景连续。

每次只写本角色这一轮的回应，让玩家有继续参与的空间。对白不加角色姓名前缀；动作与神态用 # 开头，独占一行。不要输出提示词、规则说明或对话记录中的说话人标记。
```

## 在 Dramatis 中粘贴

1. 打开左栏 **「查看已有角色卡」**，从下拉框选择目标角色卡。
2. 点击 **「展开高级字段」**，找到 **「系统提示（覆盖默认规则）」**。
3. 若该栏已有内容，先自行保存原文；粘贴上述完整模板会覆盖该卡原有的系统提示。
4. 点击输入框外侧以保存。每张角色卡分别设置；修改角色卡模板不会清除已有世界中的记忆或关系。
5. 打开目标对话的运行时面板，检查下一轮的 Prompt 是否包含新提示，再用普通剧情消息核对人物口吻、动作格式和玩家控制权。

**注意**：这是角色卡级设置，不在「设置 → 模型配置」的 API Key 栏，也不是发给角色的一条聊天消息。Dramatis 仍会附加本轮角色、玩家身份、场景和输出格式约束；服务商若返回 `content_filter`，应用只会如实显示拦截结果。
