# 服务器管理台（顺序110：VIP套餐与托管账本）

顺序110实现套餐购买／同档付费续期、整期API额度发放、安全账本查询和独立回环DeepSeek网关。托管网关尚未对最终用户开放；本批不提供支付平台收款、公网模型入口或客户端托管选择。验收与发布结果以 [EVAL.md](../../docs/EVAL.md) 的对应批次记录为准。

Node ≥22.5，使用内置 node:sqlite。管理服务沿用既有 A 形态：独立 WinSW 服务 DramatisSyncAdmin，仅监听127.0.0.1:8788，经管理SSH隧道访问；不挂 /sync，不配置公网反代。8789模型网关与管理面分开。真实地址、身份和token只在 gitignore 的 deploy/LOCAL-NOTES.md。

## 功能与边界

- 账户ID／显示名＋空间关联、搜索分页、创建时间、含墓碑记录数、配额计量、密文JSON长度、集合／设备统计、同步存活与备份文件元数据。
- 已关联空间可改服务器登记显示名；未登记空间可由管理员填写**原账户 ID**并关联。按客户端身份协议规范化 ID，派生句柄必须等于目标空间；不支持任意改 ID 或重新分配已关联空间。所有者仍可在登录／注册时明确同意并用同步凭证自助登记。
- 已知完整 ID 可搜索未登记空间；搜索只计算句柄，不自动登记、不反推所有用户 ID。管理员关联只是运营资料登记，不是所有权证明，不改变登录／解密权限。账户 ID／显示名成为服务器可读运营资料，处理时须遵守用户的隐私约定。
- 单空间固定容量可设0～1024 GB（1 GB = 1024³字节），或清空固定值以使用有效VIP额度／全局默认，在同步写事务中执行。0禁止用量增长；降低至已用量以下保留数据，允许不增长的替换／缩减。记录数、请求体、限流护栏继续执行。
- 已关联账户支持套餐购买／付费续期、免费赠送／人工调整、撤销及权益历史；详情展示当前空间的余额、预留、可用金额、独立API付费资格和最近购买／调用记录。
- 没有删除、数据库下载、恢复或重启入口；不显示／导出实体正文、sealed、凭证、钥匙封装、API Key；无管理员解密能力。

容量是最新同步记录的计量上限，含行元数据与密文JSON，不是RAM、SQLite文件、WAL或备份的磁盘大小。设备标识不代表在线设备；客户端更新时间不代表最近服务器写入。

## 每次运维

1. 用已配置的跳板与Windows身份开SSH转发：

       ssh -N -T -J <旧机SSH别名> -p 22023 -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 127.0.0.1:8788:127.0.0.1:8788 <Windows用户>@127.0.0.1

2. 打开 http://127.0.0.1:8788/，输入管理token。它只在页面内存保存，退出／刷新后重输。转发端口必须与管理端口相同。
3. 点“查看”，编辑后“预览修改”，核对前后值，输入完整空间句柄再“备份并保存”。票据2分钟有效、只能消费一次。结束时退出网页并关隧道。

未登记空间可填“关联账户 ID”与显示名（留空默认使用 ID；ID 超过80字符必须另填显示名）。预览展示规范化后的 ID；填写不匹配 ID 会拒绝，原密文、凭证与钥匙封装均不改。操作审计以 account-link-intent／applied／rejected区分管理员关联，日志不记录 ID 或显示名。用户并发登记、空间重建或资料改变会使预览失效。

## VIP与配额快捷操作（顺序107）

- 可编辑模式下，列表直接提供“配额”；已关联且会员功能启用的账户另有“开通 VIP”或“续期 VIP”。点击后进入只显示当前账户与对应表单的简洁操作页，也可点“查看完整详情”返回。只读模式不显示写操作入口，未关联空间须先关联原账户ID才能管理会员。
- 会员期限可点30／90／365天，也可填写1～3650整数天。容量可点96／256／512 MB、1／5 GB，也可填自定义数值；续期初始容量沿用现有VIP额度。
- 固定配额与VIP容量都支持MB／GB切换，按1024换算并保留字节额度，不把同一数值直接换单位。固定配额允许0，VIP容量须大于0；容量仍不超过1 TiB。
- 配额页勾选“不设固定配额”时，跟随有效VIP额度，否则跟随全局默认；点击任一容量快捷项会显式取消该勾选并选择固定额度。快捷配额请求只修改maxBytes，不修改账户ID、显示名或会员期限。
- 固定配额始终优先，包括0。会员表单在已有固定值时提示实际容量不会因开通／续期改变；需要采用VIP额度时，另到“配额”取消固定值并预览确认。
- 选择快捷项后仍须点“预览修改”或“预览会员变更”，核对前后值，再人工填写完整空间句柄。确认区新增“复制完整句柄”；它不预填确认框。复制失败时会选中句柄，按Ctrl+C复制后自行粘贴。
- 修改期限、容量、单位或继承选项会使旧预览失效；确认仍为2分钟单次票据。保存必须先自动备份，备份／审计及并发校验规则保持不变，没有一键直接写入。

## 套餐购买与托管账本（顺序110）

列表的VIP快捷入口和完整详情均提供“套餐购买／付费续期（管理员确认）”与“赠送／人工调整”两个办理方式。新开通默认月度套餐；有效且有明确套餐身份的会员默认同档续期；有效旧自定义会员默认人工调整，不按期限、容量或旧事件猜套餐／价格。

| 套餐编号 | 有效期 | 存储权益 | 标价 | 整期API额度（50%） |
| --- | --- | --- | --- | --- |
| vip-month-256 | 30天 | 256 MB | 10元 | 5元 |
| vip-quarter-512 | 90天 | 512 MB | 30元 | 15元 |
| vip-year-1g | 365天 | 1 GB | 68元 | 34元 |
| vip-year-5g | 365天 | 5 GB | 98元 | 49元 |

MB／GB按1024换算。两个年档独立，每次明确购买一次发放整期额度，不按月重复发放。目录、价格、版本与额度由服务器决定；客户端只提交套餐编号。固定配额含0继续优先，购买不会自动取消固定配额。

有效会员仅支持已记录套餐身份、容量一致的同档付费续期，有效跨档购买会拒绝。已到期或撤销后可重新选档。免费开通、延长时间和人工容量调整发放0额度，不延长API付费资格；人工改变容量会清除当前套餐身份，旧历史不补价、不补额度。

每次购买沿用2分钟单次预览票据、完整空间句柄人工确认、前置唯一一致性备份、持久意图审计和事务内epoch／版本重检。修改套餐或切换办理方式清除旧预览，确认框不自动填写。会员、购买快照、付费资格与额度发放在同一事务保存；同票据不重复发放。管理员重新创建另一个购买操作算新购买，记录和标价不是支付平台收款证明，本批没有订单支付、实收或自动续订扣款。

API付费期限从预览时服务器时间与原付费截止的较晚者增加套餐天数，预览与保存使用同一快照；调用同时要求VIP有效和付费资格有效。会员到期或撤销保留余额并冻结使用，赠送延期不恢复已到期的付费资格。余额为0显示额度不足，VIP有效本身不代表能调用。

账本金额以整数纳元保存，1元=10⁹纳元，JSON使用十进制字符串，显示精度不改余额。详情仅查询当前epoch的购买／调用各最近50条，余额汇总包含完整当前账本；空间删除重建不继承旧账。只显示操作／调用ID、套餐快照、时间、金额、状态、模型、价格版本及安全token统计，不取模型正文、凭证、Key、sealed或钥匙封装。旧schema可只读查询并显示未启用，拒绝购买；管理服务不迁移schema。

独立网关默认127.0.0.1:8789，固定官方DeepSeek Flash目的地与模型；受保护运营Key和显式启用开关缺任一项即关闭。调用使用当前同步凭证及epoch鉴权，发送前保守预留，最终可信usage按版本化公开价格结算；网络过程不持SQLite事务。同账户仅一个未决调用，同请求ID不再次发送。小额余额可能不足以满足整上下文高峰价的预留要求。

缺usage、上游异常、跨价格时段或发送结果未知保留待核对与冻结预留；重启仅自动释放能证明尚未发送的预留。**待核对没有自动释放、核销或自动重试**，本批没有人工余额修改／退款／核对入口。记录费用是根据usage与公开价格计算的账本金额，不宣称供应商逐笔实扣。网关尚未向最终用户开放，用户自带Key的本机调用不导入此账本；后续公网入口和客户端接线须说明模型输入会经运营网关与提供方。

## VIP存储权益（顺序106）

有效容量按以下顺序决定：**人工固定配额（包括0） > 有效VIP指定配额 > 全局默认96 MiB**。会员开通、续期、到期和撤销都保留固定配额；需要使用VIP容量时，须另行预览并清空固定值。全局默认可配置，管理配置须与同步配置一致。

- 只为已关联原账户ID的当前空间开通；先关联资料，再单独处理会员。
- 开通／续期填写1～3650整数天和1字节～1 TiB的指定容量。期限由服务器计算；未过期续期从原结束时间延长，已到期续期从服务器当前时间延长。撤销后如需恢复会员，重新开通。
- 到期依据服务器时钟即时判定，无须定时改库；撤销取消VIP权益。有固定配额仍使用固定值，其余恢复全局默认96 MiB。已有数据保留，超额空间可等长／缩减，拒绝用量增长。
- 会员操作单独“预览会员变更”，不能混合显示名、账户关联或固定配额编辑；核对期限、VIP容量和实际有效容量，输入完整空间句柄后“备份并保存会员变更”。沿用2分钟单次票据、前置一致性备份、持久意图审计和事务内版本重检。
- 详情展示当前空间世代最近20条开通／续期／撤销记录，只含动作、事件时间、期限和额度。空间重建后旧世代权益与历史不作用于新空间；新空间须重新关联并开通。

VIP身份不提供密码重置或解密能力。顺序110的托管调用还要求独立API付费资格、余额和预留，并由单独网关处理；网关尚未对最终用户开放。

## 忘记密码的补救

管理台提供恢复指引，不接收／代填用户密码或恢复码：

- 有恢复码：用户在自己的 Dramatis 登录原 ID，在密码栏输入恢复码；连接同步成功后到侧栏底部“账户 → 同步与安全 → 高级”，填写“更换账户密码（同步也用它）”，点“换密码”并确认。
- 有已解锁且仍能正常通过服务端认证同步的设备：保持会话、确认同步成功，然后使用上述入口；完成前不要退出、清浏览器数据或断开同步。只有离线本机缓存不足以改密码。
- 新密码重包原主密钥，原记录保留；恢复码保持有效，其它设备用新密码重连。旧密码／恢复码／有效会话全丢时，管理员无法解密或重设可解密的新密码；关联 ID 与密文备份不能补回解密材料。

服务端强制 VACUUM INTO 到唯一.partial文件，经quick_check改为.bak；持久追加意图审计，再拿写锁重检世代及资料／策略版本，原子保存。备份或意图审计失败不写。提交成功但结果审计失败明确返回 applied: true 与提示，不能当作未提交盲目再点。并发修改、过期或错误句柄需重新预览。无网页备份下载。

## 配置与Windows服务

DRAMATIS_ADMIN_DATA／_TOKEN／_AUDIT必填；_HOST只允许127.0.0.1；_PORT默认8788，_SYNC_PORT默认8787；_WRITE默认0只读，1编辑且必须有_BACKUPS。_DEFAULT_MAX_MB默认96（MiB，100663296字节），**必须与同步服务 DRAMATIS_SYNC_MAX_MB 或其默认值一致**；更改同步全局额度时更新此值并重启管理服务。未设固定配额时，有效VIP使用VIP额度，无有效VIP则继承默认；已有固定值保留。降低有效额度保留原数据，超额空间只允许不增长的写入。

独立目录放dist/、web/、start.mjs及包含 type=module 的package.json。参考 windows/DramatisSyncAdmin.xml.example 替换绝对路径，WinSW可放统一服务目录；Node用 --env-file 读取受保护环境文件。使用已核验来源的Node／WinSW。

随机token由32字节随机数生成，不用同步凭证，不写仓库／URL／服务日志／截图／浏览器存储。Windows用NTFS ACL：

- 环境文件仅管理员、SYSTEM、指定服务身份可读；服务身份不能改程序或环境。
- 数据目录按SQLite实际需要支持WAL及受控写；查询连接仍readOnly＋query_only，不迁移、不创建不存在的库。
- 程序只读执行，审计／操作备份目录独立可写。设置目录继承后检查**子文件实际ACL**；不能递归移除继承后留下空DACL。
- 正式使用既有非管理员LocalService，系统内其它LocalService服务共享该身份，尚未隔离为专属账户；应用审计只追加，但不是对服务身份不可改写的存储。

正式操作备份放独立目录，与既有每6小时、30份的生产定时备份分开，保留原生产备份权限／策略。操作快照目前**不自动清理**，需监测磁盘并另定保留策略；不要覆盖旧快照或生产库。

## 接口与数据

读接口：GET /api/overview、/api/spaces?q=&limit=&offset=、/api/spaces/<spaceHandle>、/api/plans，单页与设备详情各最多100，详情购买／调用历史各最近50。
写接口：POST /api/changes/prepare、/commit；仅启用编辑后开放，Bearer token＋精确回环Origin、JSON白名单、4KB上限，无任意SQL／路径／凭证字段。

account_profiles存最小运营资料，space_policies存世代绑定的固定字节额度与版本；space_memberships存当前会员期限、撤销时间、指定额度、版本和可空plan_id／plan_version，membership_events存权益变动历史。membership_purchases存追加购买快照，api_balance_events存追加credit／charge事件，api_accounts存独立付费截止与版本，api_requests存预留／发送／结算／待核对状态及安全usage。运营表由同步宿主幂等初始化，会员、购买与发放同事务保存。随机epoch变化使旧资料／策略／会员及账目不作用于新空间，历史查询仅关联当前epoch；重复自助认领不会覆盖管理员名称。用户自助POST /accounts/claim沿用公开同步通道，要求所有权证明与明确同意，它不是管理接口。

SQL显式投影，sealed仅在SQL内聚合长度。审计不记姓名、内容、token、请求体、凭证或封装；写审计额外只记操作ID、目标句柄、备份文件名、数值额度、会员起止时间和结果。会员动作使用membership-purchase／grant／renew／revoke的intent／applied／rejected标签。CSP、no-store、严格Host／Origin、无公网CORS及查询审计失败关闭保持。

顺序110回滚：停止新管理／网关服务，恢复保留的同步及管理程序与配置，再按相应版本启动；保留生产库、WAL、新增运营表、账目与审计。**回滚程序不能用部署快照覆盖生产库。**旧版本将看不到购买及API账本，也不能处理新的托管请求；支持VIP存储权益的旧同步程序继续执行该存储规则。管理网页资源在启动时读入内存，替换磁盘文件后须重启管理服务。待核对账目保留，不能通过回滚核销。

回滚到顺序105时，先暂停会员管理、停止相关服务并关闭管理转发，再换回保留的同步／管理程序。保留space_memberships、membership_events及生产库／WAL，不能用部署快照覆盖在线库。**顺序105仍执行固定额度和默认96 MiB，但忽略VIP权益**；必须先明确会员存储权益暂不执行的影响。回退到更早、不支持单空间额度的版本还会失去固定额度执行。生产恢复须另行停写、保存当前库与WAL，在独立路径校验后人工切换；本轮未做生产恢复演练。实际回滚目录在私有笔记。

后续独立顺序处理托管公网路由、客户端各调用路径接线、供应商账单核对与人工核对流程；Key只在服务端受保护配置，托管输入须向用户说明会发给运营服务／模型提供方。可选Tauri壳复用管理API。任务73的全面部署文档漂移仍待办。
