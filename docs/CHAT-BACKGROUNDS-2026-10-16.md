## 实现

- 设置 → 外观与显示 → 对话区背景：12个题材入口，每组3张独立场景缩略图；原生键盘操作、明确选中状态、即时预览与本机自动保存。
- 保留纯色、自选图片、背景强度、保存失败预览和重试；旧 data URL 不迁移、不丢失。未知内置路径降级纯色。
- 同源版本化 WebP：全图1600×900，缩略图480×270；只为当前题材加载缩略图，选择后加载原图。
- Service Worker 按需缓存背景图与缩略图；首次成功加载后才保证离线可用。没有预加载全部36张。
- 沿用不滚动背景层与阅读遮罩；手机题材按钮至少44px高。
- 场景图使用内置 imagegen 工具独立生成；原始PNG保留在本机生成目录，项目内交付WebP。可复用提示词见 docs/art/chat-background-prompts.json；增量编码工具见 tools/art/prepare-chat-backgrounds.mjs。
