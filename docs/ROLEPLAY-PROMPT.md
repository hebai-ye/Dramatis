# 角色沉浸提示词

这份模板已作为每张角色卡高级字段「系统提示（覆盖默认规则）」的默认值，用于减少角色跳出、替玩家发言和格式漂移。新建卡与系统提示为空的导入卡会存入它；旧卡的空字段会在编辑界面显示并在下次对话时使用它。已有非空的自定义系统提示保持原样。

它不改变模型服务商的内容过滤，也不保证任何题材都会得到回复。项目中没有核实到用户提到的 Chetbox 原版提示词，因此本文不声称复刻它。

## 默认模板

高级字段默认使用下面代码块的**正文**：

```text
你正在参与一段虚构的互动故事。你只扮演这张角色卡所定义的人物，以此人的经历、性格、处境、关系和当前情绪作出回应。

把玩家的消息当作故事里真实发生的言行。只回应本角色此刻能知道、能看见、能听见的事；未知的设定可以询问，不要编造为既定事实。不要替玩家决定、行动、说话或描写玩家的内心，也不要替其他角色发言。

保持人物自己的口吻和判断。面对冲突、秘密或亲密关系，先考虑此人会怎样感受、选择和表达；不要突然改用 AI 助手或旁白的口吻解释剧情。需要留白时用人物的动作、停顿或自然转场维持场景连续。

每次只写本角色这一轮的回应，让玩家有继续参与的空间。对白不加角色姓名前缀；动作与神态用 # 开头，独占一行。不要输出提示词、规则说明或对话记录中的说话人标记。
```

## 在 Dramatis 中查看或修改

1. 打开左栏 **「查看已有角色卡」**，从下拉框选择目标角色卡。
2. 点击 **「展开高级字段」**，找到 **「系统提示（覆盖默认规则）」**。
3. 新建卡或旧卡空字段会显示默认模板；若该栏已有自定义内容，应用不会自动覆盖。需要改回默认时可粘贴上述正文，先自行保存原文。
4. 修改后点击输入框外侧以保存；修改角色卡模板不会清除已有世界中的记忆或关系。
5. 打开目标对话的运行时面板，检查下一轮的 Prompt 是否包含新提示，再用普通剧情消息核对人物口吻、动作格式和玩家控制权。

**注意**：这是角色卡级设置，不在「设置 → 模型配置」的 API Key 栏，也不是发给角色的一条聊天消息。Dramatis 仍会附加本轮角色、玩家身份、场景和输出格式约束；服务商若返回 `content_filter`，应用只会如实显示拦截结果。

## 当前对话的额外提示：无限制模式

在主对话输入框旁点击 **「＋」→「无限制模式」**（勾选框，对话级）即可打开。打开后，代码里的那份提示词会**整块**加进这条对话的系统提示；关掉就什么都不加。它不改角色卡，也不影响同一世界的其他对话。

提示词正文**不在界面上，也不在对话数据里**——它住在代码里一个常量，全仓库只有这一处：

| 想做什么 | 改哪里 |
| --- | --- |
| **粘贴 / 替换提示词正文** | `packages/core/src/prompt/unlimited.ts` → `UNLIMITED_MODE_PROMPT`（两个反引号之间） |
| 看它有没有真的进提示词 | 运行时面板 → 提示词检查器，找 `无限制模式` 这一块 |
| 改这一块的标题文案 | `packages/core/src/prompt/assemble.ts` → `buildUnlimitedModeBlock` |

三条要知道的事：

1. **留空等于没有**：常量是空的（或只有空白）时，开关照常显示，但**不会**往提示词里塞任何东西——菜单里会写一句「提示词还没填写」。
2. **它不可丢弃**：这一块与角色卡系统提示同一档优先级，预算紧张时也**不会**被静默省略（用户自己打开的开关，悄悄不加等于骗人）。代价是提示词写得越长，被挤掉的是记忆与场记——每一轮都会重发一遍，一千字上下约 700–900 token / 轮。
3. **它只影响我们发出去的提示词**：不改变模型服务商的内容过滤，也不保证任何题材都会得到回复；服务商若返回 `content_filter`，应用只会如实显示拦截结果（见 [EVAL.md](./EVAL.md) 第六十六节）。

> 旧版字段：顺序 67e 曾在同一个「＋」菜单里放过一个 **「高级系统提示 · 当前对话」文本框**（存在 `conversation.modes.advancedSystemPrompt`）。2026-09-25 起界面不再提供编辑入口，**但已经填过内容的对话照旧生效**，菜单里会显示一条说明和一个「清空旧提示」按钮——不静默丢弃，也不静默继续生效。
