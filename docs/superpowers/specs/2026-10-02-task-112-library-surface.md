### 聊天保持挂载的具体措施

素材覆盖整个`.workspace`，使用绝对定位，不进入原grid计算；workspace增加position:relative作为参照，素材覆盖层inset:0、z-index:20。手机层级固定为素材20 < TopBar25 < drawer-backdrop26 < LeftRail30 < DialogShell40；runtime在素材模式下关闭/隔离。原MainHeader、workspace-body、CastRail保持挂载与尺寸，以 `visibility:hidden` 隐藏，以 `inert` 隔离交互，并从辅助技术阅读顺序排除。不能用HTML hidden或display:none隐藏聊天；需要明确隐藏含visibility显式覆盖规则的手机runtime子节点。

采用局部聊天可见性上下文，只控制DOM滚动、聚焦及瞬态菜单。它**不控制**消息更新、流订阅、持久化提交或交接effect。

- [StreamingBubble.tsx](<../../../apps/web/src/components/StreamingBubble.tsx>) 卸载清理会onStop并reset主流；SideChat204–209卸载清admin流。素材开关绝不触发这些清理。
- 保留MainChat664–665的conversation key及useTurnRunner稳定stop。素材状态不调用stop/reset，也不创建新的stream消费者。
- 主聊落盘后按messageId交接及隐藏期间后续角色接流继续执行；不能冻结messages。主流交接等待默认2秒，跳过确认会令后续角色停止。
- 隐藏聊天仍可布局测量；StreamingBubble76–87现有局部scrollTop追尾可继续执行。普通消息更新在隐藏期间改为只操作chat-body，不用scrollIntoView影响页面祖先。
- 打开前记录当前世界/对话标识、首个可见消息ID及相对偏移、scrollTop、追尾状态。主聊原本追尾则隐藏期继续追尾；原本读历史则保留历史锚点。收起后在layout阶段校正，锚点不存在才退回旧scrollTop，并限制在有效范围。标识变了不应用旧锚点。
- 主聊现有普通消息80px与流式120px贴底阈值保持，分别验证边界；不能关闭时无条件拉到底，也不能用旧scrollTop覆盖隐藏期新回复的底部。
- 副聊现在每块文本/工具进度都会smooth到底。仅调整隐藏期间：进入时读历史就暂停自动滚动，进入时贴底就局部追尾；关闭按历史锚点/贴底恢复，可见状态现有副聊行为本批不全面重写。
- 草稿和消息编辑状态留在原组件；记录必要的textarea选择范围，不通过卸载重建来恢复。隐藏期间禁止DOM聚焦，rAF执行时读取最新可见性；打开时关闭聊天portal菜单、清长按定时器，不清草稿。
- MainChat的focus/insertRequest带seq语义。不能简单将visible加为依赖而重放旧请求：分别记录已消费请求，隐藏时只延后尚未完成的DOM动作；恢复滚动单独处理，避免重复插角色名或跳回旧原句。

核心演示必须包括：流式中打开 → 素材里等到回复落盘及下一位接流 → 收起；气泡只有一份、无交接超时、草稿仍在，阅读历史的人仍在原位置，原本追尾的人看到最新回复。

## 4. 全量浏览、搜索、编辑及文件能力

### 本批明确做的浏览规格

- 沿用三个已有编辑器的字段、校验及session CRUD，不另造一套业务。素材区域提供宽屏列表与编辑详情；手机以列表/详情切换或单列布局呈现，进入条目不会创建会话。
- 标题显示总数N；搜索显示“找到M / 共N”。左栏入口可有三库总数徽标，计数直接来自已加载数组，不额外读库。
- 身份搜名字与设定；卡搜名字、昵称、标签、作者、人设/性格；世界书搜书名、条目标题/关键词/正文。trim与大小写归一处理；明确空查询恢复全部。
- 默认按名称稳定排序，提供“名称 / 最近修改”两种视图排序；不改仓储排序。搜索/排序只改变列表，不能因当前条目被过滤而偷偷换掉编辑对象。
- 世界书提供“全部N / 本世界已挂载K”；K按有效全库书与当前世界挂载ID交集计算，不计失效ID。列表及详情都有已挂载标识，旁边明确当前目标世界名。
- 挂载/解绑只由明确按钮触发，复用attachWorldBook/detachWorldBook。不选世界时可看全库，但挂载/解绑禁用并解释原因；浏览、搜索或切库都不能自动挂载。
- 空态区分：库为空（创建/导入入口）、搜索无结果（清筛选）、未选条目（请选择）、无当前世界（不能挂载）。删除选中项后选中相邻有效项，完全空时回空态。

### 编辑草稿与异步反馈

推荐访问过的面板在当前页面内按需保留状态，但不一次预加载三库；搜索、选择与编辑草稿不因互切/收起直接丢掉。三个已有编辑器补Promise接线、保存中/失败/重试与一致的离开协调。

- 当前App1110/1121/1133用void丢弃save Promise；身份还会在真实落库前认为已保存。改为等待真实结果，成功后才更新已保存基线，失败保留草稿，不能假报成功。统一登记并等待已经发出的保存、挂载、解绑、删除、重试Promise，不只flush尚未触发的debounce；同值flush也不能跳过仍在途的旧任务。
- 沿用现有自动保存/失焦保存语义。离开时提交仍未完成的自动保存字段并等待；图片裁切等尚待明确确认的更改，提供“继续编辑 / 放弃更改”界面内选择，不擅自保存。
- 同项收起、关闭、Esc、互切、切条目、切世界/会话使用一致路径。保存中防重复，IME组合结束再提交；失败留下原视图与错误。不新增原生confirm。
- 新建等待落库成功或保留pending条目后再选中，修复现有慢保存时选中ID尚未入数组而回退第一项的窗口。
- 删除前协调该条目的待保存任务，避免删除后自动保存把它复活。
- session部分save/attach/detach在await前捕获当前快照，保存中切会话会有旧快照覆盖风险。UI等待任务完成后才执行真实导航；但同世界的同步刷新/后台worker也会更新快照，单靠等待导航不足以保护它。对本次复用的素材写入回调做窄范围的目标世界核对与最新快照合并：完成后只补该素材/挂载/身份相关字段，保留期间新增的消息、场景与其它状态；目标世界已经变化时不把旧世界写回当前画面。补延迟保存期间后台reload的回归，不宣称因此解决全部既有并发写入问题。这里仅调整前端状态发布，不重写session，不改repository、db、存储事务或同步协议。
- WorldDesigner275的“同时从所有房间解绑”与实际软删除/当前世界解绑不符，改成真实说明，不扩大成全世界清引用或数据迁移。

### 导入与导出的实际范围（需拍板）

当前useImport会在没有世界时创建世界/首条主对话；卡的内嵌世界书还会自动挂载。**新素材库的导入必须是“仅入库”模式**：扩展现有导入hook的模式参数，复用现有PNG/JSON解析、校验与save，不新建/打开会话、不自动挂载、不改变主副状态。原左栏全局导入行为保留。

为了满足“三库每项可导入导出”的完整含义，推荐在本批明确增加独立文件能力：**三类素材的单项原生JSON导入与导出**，包括卡/书的原生类型、版本识别与字段校验；角色卡PNG导入及现有SillyTavern卡/书JSON兼容路径继续复用原解析器。**原生往返属于新增能力，不能称作搬位置就有，也不能让原生卡/书文件误走旧兼容解析。**

推荐原生Dramatis素材JSON使用类型与版本标识，只携带素材字段，不包含会话、实例记忆、账户或凭据；导入生成新ID/时间戳，同名可并存，首次不自动覆盖现有素材。卡的内嵌书可以随文件保留，但导入后不自动挂载到世界。不在本批承诺SillyTavern导出、PNG写回、批量导出或新互操作标准。

原生格式要有明确字段校验和往返测试，保存完整的头像/图片、昵称、版本、扩展字段、内嵌书与世界书位置/启停等受支持字段。不能把内部对象直接JSON.stringify后交给现有SillyTavern解析器：两边字段名称/位置枚举并不相同。此文件格式不改变IndexedDB schema或同步协议。

如果选择严格只沿用已有文件能力，则本批仅提供卡/书导入及既有世界备份入口；身份单项导入和三类单项导出明确列待办，**相应验收不能标为三库均具备独立导入导出**。两种口径需用户选择后再落地。

- LibraryWorkspace仅保留类型/标签、状态、标题与关闭、必要焦点逻辑。`LibrarySurface`内容通过模块级稳定loader + LazyPanel按首次打开加载；其三个编辑器各自动态import，首次未访问的其他库不主动挂载。

- Suspense只包内容，不包聊天或关闭外壳。首次显示“正在加载身份库/世界书/角色卡…”（role=status）；失败有role=alert及“重试加载”，重建失败lazy边界。失败、离线或重试都不会停止聊天、切会话或挡住关闭。

- 真实构建按入口与所有静态预载JS合计比较，另报gzip、CSS、每个lazy分包以及SW后台预缓存。首屏不能纳入素材编辑器重内容，总量以同环境基线不增加为验收目标；若增加，先找出静态依赖，再处理并如实报告。
- 局部状态Provider隔离activeView，并稳定App提供的list插槽与回调；手机抽屉状态引起的必要App更新单独计数。LeftRail选中态、标题及聊天可见性消费者允许常数次更新。稳定业务回调，不让onStop随activeView变化，不将搜索输入传入MainChat/MessageList。
