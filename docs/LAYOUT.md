# 界面与交互规格

> 来自手绘草图与逐区域填写，记录「界面长什么样、怎么动」。实现以此为准；与当前实现有偏差的地方见文末差异表。

## 骨架

```
┌────────────────────────────────────────────────────────────┐
│ [折叠]  顶栏（预留：未来的世界视图）                        │
├──────────────┬─────────────────────────────────────────────┤
│ 新建对话      │ 世界名 · 对话名 · 在场角色      [主/副对话] │
│              ├──────────────────────────────┬──────────────┤
│ 世界与对话列表│                              │              │
│ （可滚动）    │  对话流                      │  角色栏      │
│              │                              │  （可拖入）  │
│              │  ┌────────────────────────┐  │              │
│ 设置          │  │ 输入                + │  │              │
└──────────────┴──└────────────────────────┘──┴──────────────┘
```

## 各区域职责

### 顶栏

- **左上角**：折叠左栏
- **其余部分**：目前未设定功能。**预留**给未来的「世界视图」——以节点网络蓝图显示角色、物品、事件之间的联系

### 左栏 · 顶部

四个按钮：

1. **新对话**
2. **查看已有世界书**（导入 / 删除世界书）
3. **查看已有角色卡**（导入 / 删除角色卡）
4. **创建** —— 走副对话，由 AI 帮忙起草，用户决定去留

也就是说素材管理（导入、删除、手动微调）留在左栏顶部，**从零创建走副对话**。

### 左栏 · 中间（可滚动）

- 层级是 **世界 = 项目**，一个世界下可以开**多个对话**
- 支持**归档对话**：把情绪、关系、记忆**回滚到该对话开始之前**——相当于这条时间线没有发生过，但对话本身被保留
- 归档后的对话不在主列表里，改从**设置**中打开

### 左栏 · 底部

设置，用于配置 API 等；**已归档的对话也从这里打开**。

### 主区 · 标题栏

显示当前世界名与对话名；显示当前场景内的角色，实时刷新。

### 主区标题栏 · 右上控件

切换**主对话 / 副对话**状态。

### 主区 · 内容

**主对话状态**（角色扮演）：

- 类似 QQ 群聊：圆形头像、名字、对话内容
- 对话内容用正常聊天气泡
- **角色动作用 `#` 新开一段，且不在气泡内**
- 一段话里掺杂动作时切分成多段：对话 → 动作 → 对话
- 长对话可以拆成多个短气泡，以显出真人感

**副对话状态**（世界管理）：

- 界面上是「世界管理员与用户」的对话
- 内容是正常的 AI 工作流：创建角色、创建设定
- **不用气泡**
- 管理员产出的角色卡、世界卡由用户决定去留
- **需要真实调用工具**
- 此时 AI 不是任何角色

### 输入区

- 开启新对话时：投入**世界卡**与零或以上角色卡
- 「世界卡」就是世界书，不是另一种资产
- 底部一排按钮，其中：
  - **加号**：设置当前对话模式
  - **场景**：输入/切换当前场景。**切换场景后，角色们要主动互动**，而不是静静地换一个地点字符串
- 对话模式包括：
  - 是否所有角色必须在主角发言后才能发言
  - **静默模式**：主角长时间对话期间，其他角色只能做动作；关闭后其他角色开始说话

### 右缘窄栏

- 显示各角色
- 把角色从这里**拖进对话**，角色进入当前场景
- 在这里打开角色，显示角色详细信息

**这一栏是真实存在的**，不是草稿纸格线。

## 与当前实现的差异

现状：三栏（设定侧边栏 ｜ 对话 ｜ 运行时面板），且「房间」既是世界又只有一条对话线。

| 需要的能力 | 现状 | 影响面 |
| --- | --- | --- |
| 顶栏左上角折叠按钮 | 折叠按钮在左栏内部 | 小 |
| 世界 → 多个对话 | Room 只有一条对话线 | **模型改动 + 迁移** |
| 归档对话与影响索引 | 无 | 新能力，依赖上一项 |
| 主对话 / 副对话 | 无 | 新模式 |
| 副对话的真实工具调用 | 无 | **需要 tool calling** |
| 动作 `#` 分段渲染 | 全部渲染成气泡 | 渲染器 + prompt |
| 会话级模式（静默等） | 只有场景级入场策略 | 新增字段 |
| 右栏角色拖入 | 有「加入场景」按钮 | 改为拖拽 + 详情 |
| 世界卡 | 只有角色卡与世界书 | **新资产类型** |
| 左栏三段结构 | 是「设定侧边栏」 | 重构 |
| 世界视图蓝图 | 无 | 未来 |

## 待确认

已定：世界卡＝世界书；归档＝回滚情绪/关系/记忆到对话开始前，对话保留并可从设置打开；素材管理在左栏顶部，创建走副对话。

仍未定：

1. **副对话需要调用哪些工具**：先只做「起草/修改角色卡、世界书、场景」，还是要更广？
2. **主对话与副对话**是同一条聊天流的两种渲染，还是两条独立的记录？
3. **切换场景后角色如何互动**：是立刻让在场角色按调度各说一句，还是只是把新场景写进上下文、由下一次对话自然带入？
