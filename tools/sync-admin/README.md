# 只读服务器管理台（顺序 99）

Node ≥ 22.5，使用内置 `node:sqlite`。管理服务只监听 `127.0.0.1`，不挂在 `/sync` 下，不配置 Caddy/nginx 公网反代。本批未部署。

## 已实现

- 账户 ID／显示名与空间关联；旧空间显示“未认领”。资料由持有有效同步凭证的用户自愿登记，管理员不能代填归属。
- 搜索、分页、空间创建时间、记录数（含墓碑）、配额计量用量、密文 JSON 字节数、集合／设备统计。
- 同步服务存活检查与备份文件元数据；文件存在不表示恢复已验证。
- GET 白名单接口、Bearer token、严格回环 Host／Origin、无公网 CORS、CSP、禁止缓存、追加审计。

没有配额修改、VIP 发放、删除、数据库下载、恢复、服务重启入口。没有实体正文、`sealed`、凭证、钥匙封装或 API Key 展示／导出入口。

## 构建与隔离验收

```powershell
pnpm build:sync-server
pnpm build:sync-admin
pnpm --filter @dramatis/web build
pnpm test:sync-admin
node tools/sync-admin/smoke.mjs
```

最后一条会在操作系统临时目录创建独立测试库，启动回环测试网页、同步服务和管理台（17880／17887／17888）。脚本中的 `fixture-*` token 是公开的测试假值，只能用于此隔离测试。Ctrl+C 停止测试进程；不接触生产库。测试目录保留，便于检查审计与数据。

## Windows 运维准备（未来部署时执行）

1. 独立服务目录放 `dist/`、`web/`、`start.mjs`、Node 与 WinSW；使用 `windows/DramatisSyncAdmin.xml.example` 的泛化模板，核验可执行文件绝对路径。不要把服务加到公网站点。
2. 参考 `.env.example`，在服务器受保护的 `secrets/admin.env` 填真实数据路径、独立审计 `.jsonl` 路径、备份目录；同步健康端口默认 8787，管理端口默认 8788。环境文件不放仓库，也不与日志共用目录。
3. 本机离线生成随机 32 字节 token：`node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"`。只存入受保护环境文件，不用同步凭证，不放命令参数、URL、截图或工单。启动时使用 Node `--env-file`。
4. 用 NTFS ACL 撤销继承的普通用户权限：环境文件仅指定服务身份和管理员可读；审计目录仅服务可追加、管理员可查；同步库及其 WAL 所在目录按 SQLite 在该 Windows 环境实际需要授予最少权限。管理员查询连接同时使用 `readOnly` 与 `query_only`，不执行迁移、不创建不存在的数据库；先拿一致性备份副本验证 WAL 读取与权限，不能靠全目录写权限掩盖错误。
5. 用独立服务身份运行并检查只绑定 `127.0.0.1:8788`。保留 SSH 与 Windows 登录权限边界。WinSW 服务身份、ACL、自动启动尚未在正式服务器实测。

配置名：`DRAMATIS_ADMIN_DATA`／`_TOKEN`／`_AUDIT` 必填；`_HOST` 仅允许 `127.0.0.1`；`_PORT`、`_SYNC_PORT` 可调；`_BACKUPS` 可选。缺备份配置显示“未配置／不可读”。不显示数据库绝对路径。

## 利用现有 Windows 管理反向隧道

旧入口机的回环 22023 已转发到 Windows SSH 22。客户端 SSH 配置里准备旧机跳板别名和 Windows 身份后：

```text
ssh -N -T -J <旧机SSH别名> -p 22023 -L 127.0.0.1:8788:127.0.0.1:8788 <Windows用户>@127.0.0.1
```

真实 SSH 账号／地址／密钥路径仅写本地 SSH 配置或 gitignore 的 `deploy/LOCAL-NOTES.md`。每次运维三步：启动隧道 → 打开 `http://127.0.0.1:8788` → 输入管理 token；结束时退出网页并关闭隧道。浏览器中的 token 仅内存保存，不写本地存储／Cookie；刷新后重输。转发本地端口须与管理端口相同，严格 Host 校验不接受任意别名／端口映射。

## 接口与数据口径

管理端仅 `GET /api/overview`、`GET /api/spaces?q=&limit=&offset=`、`GET /api/spaces/<spaceHandle>`。最大单页 100，设备详情最多 100 个当前记录设备标识。设备数不是安装数或在线数；客户端 `updated_at` 不是最近服务器写入时间。

`heads` 的 `head`／`record_count`／`byte_count` 对应同步服务已有版本与配额口径；密文 JSON 长度另行聚合，两者不等于数据库磁盘大小。缺历史计数器显示“未知”，不回填。当前限流窗口在同步进程内存中，不假造用量／使用率。

用户资料登记是独立的用户自助接口：同步服务 `POST /accounts/claim`（网页通过现有 `/sync/accounts/claim` 到达），最多 4 KB，必须显式同意、提供匹配账户 ID 和现有密码／恢复凭证证明。新增 `account_profiles` 表由同步服务创建；空间的随机 `epoch` 绑定认领世代，删除重建后旧资料不可串名。它不是管理接口，不接收密码、恢复码、Key 或密文正文。旧服务器未支持或登记失败，不阻止账户登录／注册，而是提示并继续。

只读审计固定字段为时间、动作标签、状态、耗时，不记用户资料、请求路径／查询、token、请求体。审计失败时查询失败关闭，避免未经记录返回运营资料。

## 回滚与后续

停止独立管理服务并关闭 SSH 转发即可撤掉管理入口，保留审计。回滚客户端／同步程序到上一版，新增资料表可以保留，旧同步协议不读取它；不要删除生产表或覆盖同步库。若需数据库恢复，先停写、保存当前库与 WAL 状态，在独立路径恢复并校验后再由人工切换；管理台没有恢复按钮。

后续独立顺序再做单空间存储配额与服务权益：配额必须服务端写入事务执行，确认完整句柄、操作前一致性自动备份、失败拒绝写、追加审计。VIP 应有有效期、服务目录、独立调用额度与撤销记录，托管 API Key 只保存在服务端秘密配置，客户端只取服务能力。托管请求的输入需要发送给运营服务与模型提供方，必须另行明确隐私边界；本批不接线、不假承诺仍完全端到端加密。Tauri 壳可后续复用查询 API。
