密码恢复指引

请让用户在自己的设备上操作。不要将密码、恢复码或 API Key 发送给管理员，也不要填入本管理台。

用户有恢复码

  1. 在 Dramatis 登录原账户，填写原账户 ID，在密码栏填写恢复码。
  2. 同步连接成功后，打开「设置 → 账户 → 高级」，填写「换同步密码」，确认更改。
  3. 其它设备使用新密码重新连接；恢复码保持有效，原数据保留。

用户有已解锁并能正常同步的设备

保持该设备的会话，先确认同步成功，再按上述路径换同步密码；完成前不要退出、清除浏览器数据或断开同步。仅能查看本机缓存、但无法通过服务器验证的设备不足以重设密码。

旧密码、恢复码和有效同步会话都丢失时，管理员无法解密原数据或替用户重设可解密的密码。关联账户 ID 只登记资料；服务器备份保存密文，不能替代恢复码。

未登记空间可由所有者同意登记，或由管理员校验原账户 ID 后关联。关联、名称、容量及会员变更都需完整句柄确认和前置备份。普通账户默认 96 MB；固定配额优先于 VIP 权益。托管 API 服务尚未接通。
